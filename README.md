# ngx-multi-select-input Demo

This repository contains the live demo for [ngx-multi-select-input](https://github.com/noredinebahri/ngx-multi-select-input), a modern, customizable Angular standalone component for multi-term input with chips, autocomplete dropdown, and beautiful color support.

## Live Demo

Visit the live demo at: [https://noredinebahri.github.io/ngx-multi-select-input-demo](https://noredinebahri.github.io/ngx-multi-select-input-demo)

## Main Repository

For the source code, documentation, and to contribute to the project, visit the main repository:
[https://github.com/noredinebahri/ngx-multi-select-input](https://github.com/noredinebahri/ngx-multi-select-input)

## Installation

```bash
npm install ngx-multi-select-input
```
